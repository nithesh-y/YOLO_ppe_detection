# 🦺 PPE Detection using YOLO


A custom YOLO-based Personal Protective Equipment (PPE) detection system developed using Python and Ultralytics YOLO. The model detects safety equipment in images and videos by drawing bounding boxes with class labels and confidence scores.

## 🚀 Features

- Custom YOLO PPE Detection
- Video inference
- Real-time bounding box visualization
- Confidence score display
- Automatic output video generation
